## Итерации разработки

### 0. Foundation
- Репозиторий, TypeScript, линтер/форматтер, CI, тесты, окружения development/preview/production.
- Supabase project; миграции, начальные RLS-policy tests; Cloudflare Pages preview.
- i18n ru/cs/en, 4 учетные валюты (CZK/EUR/USD/UAH), денежные форматтеры и ограничения mixed-currency, дизайн-система и responsive shell.

### 1. Solo core (проверяем расчеты на реальных двух сменах)
- Auth email/Google, профили.
- Vehicles, Platform preferences и snapshots.
- CRUD личных смен + расчет топлива, комиссии и прибыли.
- Личный Dashboard, история и базовые графики.
- Unit tests для денег, времени, километров, периодов, округления.

### 2. Collaboration core
- Workspaces с валютой пространства, invite flow, roles.
- Duo shifts с долями, подтверждение и редактирование по ревизиям.
- Агрегаты команды **только по совместным сменам**, RLS и privacy tests.
- История изменений/разбор конфликтов.

### 3. Expense and settlement core
- Разовые расходы и доли.
- Реальные даты начала/окончания аренды, деление по дням отчета и отсутствие дублей.
- Обязательный получатель выручки в дуо-смене и плательщик затрат.
- Балансы кто кому должен, погашение, инвариант «платеж не меняет прибыль».

### 4. MVP release
- Экспорт своих доступных данных в CSV/JSON.
- Тесты end-to-end на iPhone-размере и desktop; восстановление сессии.
- Полные переводы трех языков, валидации и пустые состояния.
- Политика приватности, обработка удаления аккаунта, бэкапы, мониторинг ошибок.
- Деплой с production URL, onboarding первых пользователей.

## Definition of Done

- Релиз проходит unit + integration + E2E + SQL access tests.
- Сценарий «A арендует, A и B делят расходы, выполняют общую смену, B погашает долг» дает математически корректный результат.
- Разные пользователи не могут читать чужие приватные смены ни напрямую, ни через экспорт.
- Весь критичный интерфейс переведен на ru/cs/en; 4 валюты корректно работают в отдельных личных и общих пространствах.
- Мобильный UX реально удобен на узком экране, desktop не выглядит растянутой мобильной версией.
- После deploy работает login callback, deep links и обновление SPA-маршрутов.

## После MVP

- Импорт CSV/JSON с предпросмотром, дедупликацией и откатом.
- Сегменты смен и split по разным периодам/напарникам внутри дня.
- PWA и offline-first режим.
- Дополнительные OAuth провайдеры.
- Напоминания об аренде, аналитика по времени дня, сравнение машин, расширенный набор виджетов.
- Конвертация валют по FX-курсам, мультивалютные операции внутри одного workspace и коммерческие тарифы — после проверки потребности.

## Открытые решения перед SQL migration

1. Будет ли переключатель валюты менять **валюту новых записей**, или пользователь хочет видеть автоматический пересчет уже существующих сумм? Для MVP предложен первый вариант.
2. Начисление дохода vs фактическое получение денег: предлагаем хранить `payout_status = pending/received` и дату реального получения, чтобы не считать невыплаченные деньги погашенными долгами.
3. Кто может менять состав участников аренды в середине периода и как согласовать изменение; по умолчанию только согласованная корректировка.
4. Общие расходы на машину могут существовать без совместной смены; личные заработки других участников в workspace не показываем.
5. Для расчета длительности и даты разнесения аренды используем локальный календарь workspace, timestamp в UTC и корректное поведение на DST.
